# `scipy-india`/`planning`

This is a repository that exists as a compass for planning and coordinating all things SciPy India. We use GitHub issues to track tasks and projects across multiple work streams, including:

- Event planning (e.g., community calls, sprints, workshops, conferences)
- Outreach and marketing (e.g., social media campaigns, newsletters)
- Community engagement (e.g., member onboarding, feedback collection)
- Documentation and resources (e.g., guides, FAQs, tutorials)
- Website and infrastructure (e.g., updates, maintenance, new features)
- Fundraising and sponsorship (e.g., grant applications, sponsor outreach)
- Collaboration and partnerships (e.g., joint events, cross-community initiatives)
- Governance and administration (e.g., elections, policy updates)
- Miscellaneous tasks (e.g., ad-hoc projects, special initiatives)
- Long-term strategic planning (e.g., vision setting, roadmap development)

## How to use this repository

If you are a volunteer member of the SciPy India community, you may be invited to this repository to help with planning and coordination. Here are some guidelines on how to use this repository effectively:

1. If you have a task, project, or idea that needs to be tracked, please create a new issue in this repository. Use clear and descriptive titles, and provide as much detail as possible in the issue description.
2. We encourage collaboration and discussion around issues, so feel free to tag relevant community members and request their input.
3. We like to plan everything in the open. Please avoid using private or sensitive information in issues, and be respectful of others' privacy and confidentiality.
4. For major projects or initiatives, consider creating a project board to organise related issues and track progress.
5. Feel free to use labels, milestones, and assignees to categorise and prioritise issues.
6. If you complete a task or project, close the corresponding issue to indicate that it is done.
7. Regularly review and update issues to ensure they are still relevant and accurate and to keep the community informed of the progress made.
8. If you have any questions, suggestions for improvement, or need help using this repository, reach out to the SciPy India community on Zulip in a new thread.
